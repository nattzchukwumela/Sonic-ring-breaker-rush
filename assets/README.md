# Source assets

This directory stores original sprite sheets, unused alternatives, design-source
files, and asset notes. These files are kept outside `public` so Vite does not
copy them into the production build.

- `source/graphics/sprite-sheets`: original sheets used to extract game sprites
- `source/graphics/backgrounds`: unused or source-quality backgrounds
- `source/graphics/legacy`: older graphics retained for reference
- `source/sounds`: unused and incomplete audio files
- `source/fonts`: unused font files
- `notes`: local asset-source notes

Only optimized files currently loaded by the game belong in `public`.
